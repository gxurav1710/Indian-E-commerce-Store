Cloudflare Tunnel Deployment Guide

Zero-Trust Public Hostname Routing Guide

To deploy this platform live without opening firewall ports or risking public IP exposure, create a single Cloudflare Tunnel (cloudflared) and map the exact 13 Public Hostname Routes below:

Public Subdomain Target Service Port Service Role
vienta.shop APEX ROOT STORE http://localhost:5000 Customer Storefront (domain.com)
api.vienta.shop http://localhost:5001 Commerce REST API
pay.vienta.shop http://localhost:7000 Payment Checkout UI
pay-api.vienta.shop http://localhost:6100 YouPi Core Payment API
merchant.vienta.shop http://localhost:6001 PG Merchant Admin
admin.vienta.shop http://localhost:5050 Store Admin Panel
control.vienta.shop http://localhost:8090 Control Center Console
whatsapp-api.vienta.shop http://localhost:4000 WhatsApp Auth API
whatsapp-worker.vienta.shop http://localhost:4001 WhatsApp Worker Daemon
whatsapp.vienta.shop http://localhost:4002 WhatsApp Dev Dashboard
core.vienta.shop http://localhost:8085 Core Process Handler
shipping.vienta.shop http://localhost:5003 Shiprocket Surface Calc
notify.vienta.shop http://localhost:5002 Notification Service

Step-by-Step Tunnel Execution:

  1. Login to Cloudflare Dashboard → Zero Trust → Networks → Tunnels.
  2. Click Create a Tunnel → Name it ecommerce-unified-prod.
  3. Run the connector command displayed on your host terminal (Windows / Linux).
  4. Under Public Hostnames, add the 13 mappings listed in the table above pointing to HTTP and localhost:PORT.
  5. Enter your domain in the Quick Domain Deployer on the left, click Convert All URLs, and click Push Credentials Directly to Code.
